## 0. 诚实红线(命门)
- **纯描述·无晋升**(用户拍板·B1/S1/S2 核心):本研究**永不**输出"edge-candidate/信号"。只出"历史上高/极端
  恐慌后市场怎么走"的描述 + CI + 稳健性,**明标非信号非荐股**。想把它做成抄底信号 → 停(§8)。
- **样本真相 = ~5-6 次独立危机,不是几百天**:VIX 高企是一段(危机常持续数月)。逐日算=把一次危机重复计几十次、
  假装 N 大。**去聚集**(§1.3·危机重置法)后有效 N 就是十来次危机级事件;**报有效事件数,不报天数**。
- **数据 2000+**(B1 修正·此前我误写 1990+):`combined_prices.csv` / `VIX.csv` 的 VIX 均从 **2000-01-03** 起,
  仓库无 1990s VIX。故没有 1990-91/1998-LTCM 那些危机;OOS 只能"分 2000-09 与 2010-今两半看是否同向"(§4·已降级)。
- **VXSMH 移出本研究**(S4):仅 ~10 个月 live 历史、不在 combined_prices、连一个极端事件都凑不出,且
  `risk_dashboard.py:57-61` 已明标它"不能回测/不进信号链"。本研究**只做 VIX**;VXSMH 留 risk_dashboard 的
  纯描述读数,等它攒够数年历史再议(一句话带过,不建 JSON 块/不建卡/不写测试)。
- **多窗高度相关 + 阈值分层**:4 窗 × 3 触发器 × 2 指数 = 多组且高度相关,"某组看着显著"几乎必然。因**纯描述不晋升**,
  多重性不再是"门作弊"风险,但仍**事前钉一个 primary 单元**(§2)当头条,其余明标 secondary/探索,绝不喊"某处显著=有料"。
- CI 含 0 但点估计好看想淡化 CI、或想略过 LOCO → 停(§8)。过去≠未来、会错、非投资建议。

## 1. 事件定义(全冻结·绝对阈值·PIT 平凡)
### 1.1 恐慌序列
- **VIX**:`combined_prices.csv` 的 `VIX` 列(2000-01-03+·以数据实测为准)。仅此一个;无 VXSMH。
### 1.2 触发器(3 个·绝对阈值·事前冻结·round number 无 DoF·并列报告不择优)
> 用**绝对阈值**而非滚动分位:① 可解释("VIX 到 30/40"人人懂)② PIT 平凡(无 rolling 窗/warmup 调参空间·消解 S5)
> ③ 审计发现滚动 90 分位一天里 12% 都触发=不 extreme(B2)。绝对阈值把"高"和"极端"如实分层。
- **T1 高恐慌**:VIX 日收盘 **≥ 30**(=primary 层·事件较多·够说点东西)。
- **T2 极端恐慌**:VIX 日收盘 **≥ 40**(=极端层·**极稀少·~8 次(2008/2020 最深)·标"轶事级·别当规律"**)。
- **T3 骤升**:VIX **单日涨幅 ≥ +20% 且当日收盘 ≥ 25**(骤升进入偏高恐慌区。加地板 25 是因 +20% 常发生在低位
  抖动(如 13→16)、与"高/极端恐慌"主题不符——②b 修;仍冻结不调)。
### 1.3 去聚集(命门·B4·审计推荐的"重置法",非按窗冷却)
- **危机重置规则**:一次触发后,直到 VIX **先回落到 < 20(平静地板)** 之前,不再计新事件。→ 一次危机=一个事件
  (2008 从首破阈到回落<20 = 1 个事件,不是几十个)。**产出唯一一套事件集**,4 个窗**都在这同一套事件上量**
  (消解 B4:此前按窗冷却会造出 4 套不同事件集)。地板 20 冻结。

## 2. 前向收益(4 窗·同一套事件)
- 基准:**SP500 + NASDAQ**(各自并列)。入场=触发日**次一交易日收盘**(act after);前向 h ∈ {5,20,60,120} 交易日,
  `ret=px[i+h]/px[i]-1`(复用 `stats_util.forward_returns`)。
- **事前钉 primary 单元(S2)**:**T1(VIX≥30)· SP500 · 20 日** = 头条口径;其余(T2/T3、NASDAQ、其他窗)全部
  明标 secondary/探索,并列展示但不作头条。
- 每窗每触发器报:**有效事件数 N**、up 率、均值/中位、**vs 全样本基率**(同 h 任意起点·诚实参照系)、逐事件明细。

## 3. 置信区间(事件级自助·B3 修正·不用 block_bootstrap_diff)
> 审计抓出:去聚集成孤立事件后,再喂 `block_bootstrap_diff` 的 block=horizon **在事件侧不起作用**(块里只 1 个事件日),
> 等于小 N iid 自助,"块自相关校正"是幻觉。故**改事件级自助**、如实承认 N 小。
- **事件级 bootstrap**:对 §1.3 的 ~N 个独立事件的前向收益**有放回重采样 B 次**,报**均值与 up 率的 95% CI**;
  并对"事件均值 − 全样本基率均值"的差报 CI。CI 宽是诚实结果,不修饰。base_rate 侧另算(§S6:其有效 N≈n/h·
  也自相关·差的 CI 由事件侧小 N 主导·如实标)。
- N 太小算不出稳定 CI(**< 10 事件**·②b 从 8 抬到 10:T2 只 8 个、在 CI 悬崖边)→ 该(触发器×窗)标
  **`described-only·N 太小无 CI`**,绝不静默当通过(N3)。故 **T2(≥40·N≈8)全程 described-only 不出 CI**。

## 4. 稳健性(纯描述·无晋升门·LOCO 当主检)
> 用户拍板不设晋升。故这里不是"门",是**诚实稳健性披露**,防"一次危机撑起全部"。
- **留一危机稳健(LOCO·主检·S1/S3)**:**粒度=整个危机段,不是单个事件**(②b 命门·NEW-1):事件先按**连续簇/
  危机年分组**(如 2022 有 4 个 T1 事件属同一危机段·2008 的多个也是),LOCO 逐次剔掉**影响最大的那一整段危机**重算
  ——剔单个事件几乎不动,等于没做。**方向翻转或 CI 跨 0 → 明标"由单次危机驱动·脆"**;**头条数字用"剔掉最大一段
  危机后"的结果**(而非全样本·防 GFC/COVID 一手遮天)。
- **分时代仅作示意(S3·已降级)**:2000-09 vs 2010-今 两半是否同向——但如实标"era1≈网络泡沫+GFC、era2≈COVID+2022,
  本质是问两次大反弹是否同向,非独立验证"。**不作主检,不作任何门**。
- **最小效应**:描述里说"值得一提"须点估计效应有实际意义(非仅 CI≠0);否则只陈列数字不加形容。

## 5. 小样本 / 聚集告警(前端命门·必须显眼)
- 每卡强制:**有效事件数 N**(非天数)+ "极端恐慌 ~5-6 次独立危机·CI 已尽量诚实但仍宽·别当定论";
  **T2(≥40)卡强制"轶事级·基本只有 2008+2020"**;**120 窗卡强制"半年窗·重叠最重·最不可信"**。
- 顶部诚实横幅:纯描述·非信号·多组高相关·未跨组校正·极端事件天生高不确定·数据仅 2000+·过去≠未来。
