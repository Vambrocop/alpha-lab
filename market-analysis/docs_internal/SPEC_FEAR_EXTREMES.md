> 更可能出可解释的有用结果。定位:**极端恐慌之后市场怎么走**的事件研究——描述为主,带置信区间 + OOS
> 验证 + 小样本/聚集告警。**不是信号/预测/荐股**,除非过 OOS 门才谈晋升。
> 六步:①规格(本文)→ ②独立审 → ③建 → ④双审(公开统计结论)→ ⑤修 → ⑥亲验+提交。
> 与 [[SPEC_EVENT_LENS]] 关系:恐慌尖峰=事件透镜的一个事件类型,但本研究**更深**(多窗+CI+OOS),
> 结果可在事件透镜页露出,但带自己的 CI/OOS,不混进透镜"纯描述无校正"那层。

## 0. 诚实红线(本研究的命门——极值事件天生难做)
- **极值事件稀少 + 聚集**:VIX 冲高不是孤立点,是一段(恐慌常持续数周)→ 逐日算会把**一次事件重复计几十次**,
  假装 N 很大。**必须去聚集**(一个尖峰簇只算一个事件,见 §1.3)+ 报**有效 N**(独立事件数),不报天数。
- **重叠前向窗**:120 交易日窗 ≈ 半年,相邻事件的前向窗大量重叠 → 自相关严重 → 普通 CI 会**假装很窄**。
  CI 必须用**块自助**(block=horizon)吃掉重叠自相关。
- **VXSMH 太新**(2025-09 上线)→ 至今**几乎没有极值事件、无法回测**。诚实标:VXSMH 版本"史太短·N≈0·
  仅占位、不下结论";真正能做的是 **VIX(1990+)**。别拿 VXSMH 的 1-2 个点假装有研究。
- **多窗 × 多阈值 = 多重比较**:4 窗 × VIX/VXSMH × 若干阈值 → 十几组。**阈值必须事前冻结**(§1),
  不许按哪个"看着显著"挑;报告标"探索性·未做跨组 FDR·几组看着显著属随机"。
- **描述非主张**:每组亮"极值后 N 窗:up X/有效N(%)+ 均值 + CI",不下"抄底信号"结论;
  过去≠未来、非投资建议、会错。**输了(无 edge)照样登**(Kronos/EBM 先例·进 §4c)。

## 1. 事件定义(冻结·防 DoF)
### 1.1 恐慌序列
- **VIX**(主):`combined_prices.csv` 的 `VIX` 列(1990+;实测起点以数据为准)。
- **VXSMH**(辅·半导体恐慌):risk_dashboard 已接的 Cboe 半导体波动指数(2025-09+·**史太短·仅占位**)。
### 1.2 触发器(两种·各自冻结·并列报告,不择优)
- **A·水平极值**:恐慌值 ≥ 其**滚动 3 年(756 交易日)分位的 90 分位**当日收盘(自适应"对当时而言算极端",避免
  用固定 30/40 在不同波动体制下失真)。滚动分位=PIT,不看未来。
- **B·尖峰跳变**:恐慌值当日**单日涨幅 ≥ +20%**(经典"恐慌骤起"·Whaley 类阈,文献常用,冻结不调)。
- 两个触发器**都报**,不合并、不择优;哪个更有料让数据自己说,不事后挑。
### 1.3 去聚集(命门)
- 同一恐慌簇只取**首个触发日**为事件;此后 **`horizon` 冷却期**(取该窗长度)内不再计新事件,直到恐慌回落
  后再次触发才算新事件。→ 保证事件近似独立、有效 N 诚实。每个窗各自去聚集(因冷却期=窗长)。

## 2. 前向收益(4 窗)
- 基准序列:**SP500 + NASDAQ**(各自算·并列;NASDAQ 对半导体/科技更相关,配 VXSMH)。
- 事件入场=触发日**次一交易日收盘**(act after,不抢跑);前向 **h ∈ {5, 20, 60, 120} 交易日**,
  `ret = px[i+h]/px[i] - 1`。复用 `stats_util` 现成 fwd 机件,不手搓。
- 每窗报:事件数(去聚集后有效 N)、**up 率**(涨的比例)、**均值 / 中位**收益、**vs 全样本基率**(同 h 任意起点
  的 up 率与均值·诚实参照系)、逐事件明细(date + 各窗收益·供展开核对)。

## 3. 置信区间(块自助·吃重叠自相关)
- 复用/新写**块自助**:对"事件组前向收益"与"全样本基率组"各重采样,`block = horizon`(防重叠窗自相关),
  报 **均值差(事件−基率)的 95% CI** 与 **up 率差的 95% CI**。CI **不含 0** 才谈"看着有别于基率"(仍非 edge 定论)。
- **不用**普通 SE / t 检验(重叠+聚集下假装太窄)。CI 计算逐窗独立。

## 4. OOS 验证(诚实门)
- **分时代 OOS**:样本切两半(如 1990–2009 / 2010–至今),看极值后的方向/幅度是否**两代都成立**;只有一代成立=
  大概率被套利/偶然,标"不稳"。(不做参数拟合,故用时代复现代替 walk-forward 训练。)
- **晋升门**:仅当 ①CI 不含 0 ②两代同向 ③去聚集后有效 N ≥ 一个诚实下限(如 ≥15/窗)三者都满足 → 才谈"可能有
  可解释规律",且仍先进候选登记簿走既有校正,**不直接上信号**。任一不满足 → **描述性展示 + 明标"未达 edge 门"**。

## 5. 小样本 / 聚集告警(前端命门·必须显眼)
- 每窗每触发器卡片强制显示:**有效事件数 N**(非天数)、"极值事件稀少+聚集→CI 已用块自助但仍宽·别当定论"、
  120 窗额外标"半年窗·重叠极重·最不可信"。VXSMH 卡强制"史太短(2025-09+)·N≈?·占位不下结论"。
- 顶部诚实横幅(同事件透镜):探索性·4窗×2触发器×2指数=多组·未跨组 FDR·极值研究天生高不确定。

## 6. 输出与展示
- `fear_extremes.json`(web+docs):`generated`、每(指数×触发器)块:各窗 `{n_events, up_pct, mean_pct,
  median_pct, base_up_pct, base_mean_pct, diff_mean, ci95_mean_diff, ci95_up_diff, oos_pass}`、
  `events`(逐次 date + 各窗收益)、`honesty`(§0/§5 全文·机器守门)、`verdict`(晋升门四态:
  described-only / borderline / edge-candidate / no-signal)。
- 前端:并入事件透镜页或新页;muted 不红绿煽情;CI 用误差棒;活读 json;as-of 具体日期;zh/en;vp.css;无 CDN。
- **VXSMH 块**并列但打灰 + "占位·史太短"角标。

## 7. 测试(≥8·合成/固定不碰网络)
1. 触发器 A(滚动分位)PIT 正确(合成序列·不看未来);2. 触发器 B(单日+20%)阈值精确;
3. **去聚集**:合成一段持续高恐慌 → 只计一个事件(冷却期生效);4. 前向收益手算对齐(合成);
5. 全样本基率参照系;6. **块自助 CI**:合成已知差两组·CI 覆盖正确·block=horizon;7. OOS 分代逻辑
  (合成一代成立/一代不成立 → 判"不稳");8. 晋升门四态(合成各触发一态);9. honesty/小样本告警进 json
  (机器守门·防删);10. VXSMH 史太短 → 标占位不崩。

## 8. 停机点(遇到停下报告,不自行决定)
- 想按"哪个阈值/窗看着显著"改触发器/加窗 → 停(DoF·冻结集);
- 去聚集后某窗有效 N 极小(<10)却想报"有信号" → 停(报描述+大 N 告警,不晋升);
- 想把恐慌极值直接做成"抄底信号/荐股" → 停(先过 §4 门 + 候选登记簿校正,不抄近道);
- CI 含 0 但点估计好看想"淡化 CI" → 停(CI 是命门,不许淡化);
- VXSMH 想凑事件下结论 → 停(史太短·只占位)。
